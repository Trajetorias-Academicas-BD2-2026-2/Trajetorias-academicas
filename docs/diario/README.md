# Diário de bordo da Squad G2

Registro semanal do projeto, como pede a página do Projeto Integrado:
**o que foi medido, o que surpreendeu, o que foi decidido**. Um arquivo
por semana do cronograma (`semana-NN.md`), escrito na própria semana.

Regras:

- Só registrar o que aconteceu de fato. Semanas anteriores ao início do
  diário não são reconstruídas de memória; quando algo delas importar,
  citem o commit ou o PR que o evidencia.
- Número sem fonte não entra: todo "medimos X" aponta para o script, o
  arquivo gerado ou o commit.
- Decisão que muda o esquema ou a arquitetura vira ADR; aqui fica só o
  resumo e o link.
